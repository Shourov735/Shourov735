### 🌟 1. [Nabodigonto (নবদিগন্ত সমাজ কল্যাণ সংস্থা)](https://nabodigonto.conversora-tech.workers.dev/) — Flagship Community & Financial Platform

[![Stack](https://img.shields.io/badge/Stack-Next.js_16_%7C_Prisma_7_%7C_Neon_Postgres_%7C_Clerk_v7_%7C_Cloudflare-black?style=flat-square)](#)

> **Impact:** Following the successful architecture, implementation, and deployment of this platform, I was appointed as the **IT Secretary** of Nabodigonto Social Welfare Organization (*নবদিগন্ত সমাজ কল্যাণ সংস্থা*), Gazipur.

A comprehensive digital platform engineered for a grassroots Bangladeshi social welfare organization:
- **Blind Audit Protocol & Double-Signed Verification:** To prevent financial discrepancies, expected treasury balances remain masked until both the Finance Director and System Admin independently submit physical cash counts and bank statements.
- **Dynamic 3D Flip Member ID Cards:** Generates digital PVC-style identity cards with dynamic QR codes for public verification (`/verify/[token]`) while securing sensitive member details. Includes bulk PVC print-ready layout generation (`/admin/cards/bulk`).
- **Member Dues & Transparency Desk:** Self-service member hub for tracking monthly dues, instant receipts, and downloading cryptographically verified SHA-256 PDF financial audit reports.
- **Modern Cloud Architecture:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Prisma 7, Neon Serverless PostgreSQL / Cloudflare D1, Clerk Auth v7, Backblaze B2 (S3-compatible) storage, deployed serverless on Cloudflare Workers via OpenNext.

[![Repository](https://img.shields.io/badge/Repo-QuranReadingTracker-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Shourov735/QuranReadingTracker)
[![Platform](https://img.shields.io/badge/Platform-Android_%2F_Offline--First-3DDC84?style=flat-square&logo=android&logoColor=white)](#)

An offline-first Android application designed to cultivate and track daily Quran reading habits with total data sovereignty:
- **Dual Independent Reading Pipelines:** Tracks Arabic recitation (by Surah + Ruku) and Bangla translation reading (by Surah + Ayat) separately so differing habit paces never interfere.

## 🌐 Open Source Contributions

### 📦 [romankh3/image-comparison](https://github.com/romankh3/image-comparison) (Maven Central Java Library)
[![Pull Request](https://img.shields.io/badge/PR_%23255-Refactor_Region_Grouping-238636?style=flat-square&logo=github&logoColor=white)](https://github.com/romankh3/image-comparison/pull/255)
[![Upstream](https://img.shields.io/badge/Upstream-romankh3%2Fimage--comparison-blue?style=flat-square&logo=github&logoColor=white)](https://github.com/romankh3/image-comparison)
[![Assignment](https://img.shields.io/badge/Project-University_Open_Source_Assignment-8a2be2?style=flat-square)](#)

Contributed to this widely used Java QA visual testing library as part of an academic Open Source Software Engineering assignment at University of Dhaka:
- **Algorithmic Refactoring ([PR #255](https://github.com/romankh3/image-comparison/pull/255) / Closes [#254](https://github.com/romankh3/image-comparison/issues/254)):**
  - Replaced recursive difference region grouping with an iterative `ArrayDeque` traversal, protecting against stack overflow errors during large connected image diffs.
  - Replaced per-pixel `new Point(x, y)` object instantiations during exclusion checks with coordinate-based checks, dramatically reducing memory overhead and GC pressure.
  - Eliminated transient comparison state stored on the class instance, refactored rectangle merging to "merge until stable", and added regression tests.
  - Passed 100% of the test suite (66/66 JUnit tests), PMD code quality checks, and CPD duplication checks.
